# Baller visual Echo Fighter

Single-style visual Echo Fighter based on Min Min.

```text
UI character: ui_chara_baller
Base fighter: fighter_kind_tantan
Fighter directory: tantan
Marker: baller.marker
Slot: c20
Styles: 1
```

Third-party Baller assets stay outside this source repository.
## Custom series

Baller uses the custom series ID:

`ui_series_roblox`

The series icon is loaded from:

`ui/replace/series/series_0/series_0_roblox.bntx`

The series is registered by the auto-slotting plugin through
The CSK Collection API.

## Custom announcer call

The plugin registers the following custom announcer call:

`vc_narration_characall_baller`

The corresponding audio file must be installed at:

`sound/bank/narration/vc_narration_characall_baller.idsp`
