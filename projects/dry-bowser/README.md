# Dry Bowser visual Echo Fighter

First hardware-validated project in Ultimate Echo Collection.

```text
UI character: ui_chara_koopadry
Base fighter: fighter_kind_koopa
Fighter directory: koopa
Marker: koopadry.marker

```

Known presentation issues in the first functional build: the displayed name is `Bowser Skelet`, the Punch-Out title is `Le roi des os`, the VS render requires layout adjustment, and Final Smash uses regular Giga Bowser.

Original Dry Bowser assets are not redistributed by this repository.
