# Dr. Luigi Echo Fighter

Independent visual Echo Fighter entry for Dr. Luigi in Super Smash Bros. Ultimate.

## Configuration

- Base fighter: Luigi
- Fighter kind: `fighter_kind_luigi`
- UI character ID: `ui_chara_drluigi`
- Physical slot: `fighter/luigi/model/body/c20`
- Logical Echo style: `c00`
- Marker: `drluigi.marker`
- Variant: Dr. Luigi without hat

## Required plugin

Place the compiled `plugin.nro` in the root of this mod folder.
